# Kalana Lakshan — Portfolio

Personal portfolio site for [H.M. Kalana Lakshan](https://github.com/Kalana-Lakshan), Computer Science & Engineering undergraduate at the University of Moratuwa.

## GitHub Pages

This repo is set up as a static site (`index.html` at the root).

1. Push to the `main` branch of `Kalana-Lakshan.github.io`
2. In repo **Settings → Pages**, set source to **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Site URL: `https://kalana-lakshan.github.io`

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
